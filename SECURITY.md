# Política de seguridad

## Versiones mantenidas

La versión publicada en la rama `main` es la versión mantenida.

## Reporte responsable

No publiques vulnerabilidades, credenciales, datos personales ni pruebas de explotación en un issue público.

Envía el reporte a **info@movidasst.com** con:

- URL o componente afectado;
- impacto observado;
- pasos mínimos para reproducirlo;
- evidencia sin datos personales de terceros;
- una forma segura de contacto.

Confirmaremos la recepción y coordinaremos la corrección antes de divulgar detalles. No se autoriza acceder, alterar, descargar ni destruir datos ajenos; interrumpir el servicio; hacer ingeniería social; ni ejecutar pruebas automatizadas agresivas.

## Credenciales

El frontend solo contiene una clave publicable de Supabase. Nunca deben incorporarse claves `service_role`, claves secretas, contraseñas ni tokens privados al repositorio. Si encuentras uno, repórtalo de inmediato y no lo reutilices.
