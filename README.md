# Simulador de Contador Geiger-Müller

Laboratorio didáctico mobile-first de La Movida de SST Plus para practicar la búsqueda y confirmación de contaminación radiactiva superficial con una sonda tipo pancake.

## Alcance

El simulador enseña inspección, comprobación, medición de fondo, barrido, confirmación estacionaria e interpretación mediante tasa neta, umbral de decisión y límite de detección. No identifica radionucleidos y no sirve para medir haces de rayos X.

## Desarrollo

```bash
npm install
npm run dev
npm run build
```

Los resultados son educativos. Una medición real exige un procedimiento autorizado, instrumento calibrado y supervisión de protección radiológica.
