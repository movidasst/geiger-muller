# Contribuir

Gracias por ayudar a mejorar el simulador.

1. Abre un issue para acordar cambios funcionales importantes.
2. Crea una rama, ejecuta `npm ci` y verifica con `npm run build`.
3. Mantén la experiencia mobile-first, accesible y didáctica.
4. No incluyas datos personales, credenciales, material sin licencia ni marcas de terceros.
5. Envía cambios pequeños, explicados y verificables.

Al contribuir declaras, conforme al [Developer Certificate of Origin 1.1](https://developercertificate.org/), que tienes derecho a enviar el trabajo bajo la licencia del proyecto. Añade a cada commit una línea `Signed-off-by: Nombre <correo>` usando `git commit -s`.

Los reportes de seguridad siguen `SECURITY.md`, no los issues públicos.
